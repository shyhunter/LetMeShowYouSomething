LetMeShowYouSomething

Your AI agent writes down what it needs you to judge, you answer on one offline page, and your answers go back to the agent as a file it checks before it acts.

agent ──► review.json ──► one HTML page ──► a person judges each item ──► Export
agent ◄── check (PASS) ◄── feedback.json ◄────────────────────────────────┘

See the whole loop → A person answers, the page exports the answer, the checker verifies it, and the agent reports back, gaps first. Every piece is real.

Try it

Each page is the real thing: press Start, answer, and download your answers on the last step. Nothing leaves your browser until you do.

Use it

It is an agent skill with no dependencies. Install it for the agents on your machine:

npx skills add shyhunter/LetMeShowYouSomething -g

Tested with Claude Code and Codex. The README has the other ways to install it and how to run the checker.
