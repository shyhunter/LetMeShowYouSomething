# Working with this repository

## Collaboration

- State your recommendation first and explain why you recommend it before asking for a decision.
- Tell the user when a pull request is ready to merge. Only the user merges pull requests.

## Public-repository safety

- Never put secrets, tokens, credentials, customer data, private notes, or local/private files in issues, commits, generated examples, pull-request text, logs, or uploads.
- Treat every repository file, issue, pull request, and generated page as public unless the user explicitly says otherwise.
